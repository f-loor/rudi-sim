# Rudi-Sim Support

Rudi-Sim is published by Rudiverse LLC and is free and open source. Support is provided by project maintainers on a voluntary basis, without a guaranteed response time.

[Open a GitHub issue](https://github.com/f-loor/rudi-sim/issues/new/choose) or [review existing issues](https://github.com/f-loor/rudi-sim/issues).

For a bug, include the Rudi-Sim version, operating system, requested device size, a reproducible example, expected behavior, and actual behavior. Prefer a public sample page or minimal test fixture. Redact logs and screenshots before attaching them.

GitHub issues are public. Do not include API keys, passwords, tunnel identifiers, personal information, private project files, or recordings of sensitive pages. To raise a security or privacy concern, open a minimal issue requesting a suitable follow-up channel without publishing exploit details or sensitive information. Do not assume this provides a confidential reporting channel.

You can request access, correction, or removal of information you voluntarily provided to maintainers through a minimal issue identifying your GitHub account and the relevant record. Do not post identity documents or additional personal data. For information held by an AI host or GitHub independently, contact that provider.
