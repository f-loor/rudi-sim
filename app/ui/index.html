Welcome to Rudi-Sim

    Which assistants will use Rudi-Sim?

    Rudi-Sim opens your website on Apple screen sizes in Safari's engine (WebKit) and records what happens. An AI assistant drives it; you can watch and click along.

    Where should recordings go?

    Every session saves a video and screenshots in its own folder. They stay on this computer.

    Keep Rudi-Sim ready?

    Download Safari's engine

    Rudi-Sim uses Playwright's build of WebKit, the engine inside Safari. It's a one-time download of about 70–90 MB. It's browser emulation on this computer, not a real iPhone.

    Connect ChatGPT

    This is a developer setup. It uses OpenAI's tunnel-client program and a tunnel that belongs to your own OpenAI Platform organization. Rudi-Sim can't create these for you, and there's no "sign in with OpenAI" for it yet.
    1. Open Tunnels in OpenAI Platform, create a tunnel and copy its ID (it starts with tunnel_). Your role needs the Tunnels Read and Use permissions.
    2. Create a runtime API key for it on the same page or under API keys.
    3. Download tunnel-client from that page and choose it below.
    Not chosen

    The key goes straight into your computer's password store. Rudi-Sim never writes it to a file or a log.

    Simulator
    
      
    Open a site yourself, or let an assistant do it. The simulator opens in its own window, which you can click and scroll in at any time.

    All devices
    
      
      
    
        
        
        
      
    
      
    Seed makes the page's Math.random() give the same numbers each run. It doesn't freeze clocks, animations, network data or anything else.
    
      
    
      
     
    
      
    When an assistant drives the simulator, its taps and typing show up on every screen. Your own clicks in the simulator window only affect the screen you click in, and the assistant won't know about them unless you tell it.
    
      
    
      
    
        
        
        
        
      
    
      
    
    

    
    
      
    Previews
    
      
    A project file tells Rudi-Sim how to start two versions of your site (for example main and your branch) side by side. Rudi-Sim runs its commands only after you've reviewed and trusted the file here. If the file changes, you'll be asked again.
